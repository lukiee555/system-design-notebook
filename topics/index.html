How Database Indexes Work

  • Index = access path; wins by cutting page reads.
  • Optimizer may still scan - check EXPLAIN.
  • Clustered = row order; secondary = extra fetch.

B+ Tree vs LSM Tree

  • B+ tree: ranges and order; random writes, splits.
  • LSM: WAL → MemTable → SSTable → compaction.
  • LSM pays in amplification and tombstones.
Open topic →

Geospatial Indexes

  • Geohash: cell prefix + neighbours.
  • Quadtree: adapts to density; R-tree: any geometry.
  • Always finish with an exact distance check.

Inverted Index

  • AND intersect, OR union, phrase = positions.
  • DB is truth; outbox/CDC feeds the index.
